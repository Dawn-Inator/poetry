title: 诗集总索引
---

这是一份私人诗文集的完整索引，收录 2019—2026 年间创作的诗、赋、志怪小说、拟古记共 40 余篇。本仓库分三层：**原文**、**按文体分类**、**按情感基调分类**，供人类回顾，也供 AI 按此协议检索后再进行仿写。

## 目录结构

| 目录 | 内容 | 用途 |
|---|---|---|
| [`poems/`](poems/) | 全部作品原文，一篇一个 `.md`，文件名为 `日期_标题.md`，含 frontmatter（标题、日期、可选 type） | 仿写时的语料来源，永远以此为准 |
| [`style/`](style/index.md) | 按**文体**分类：楚辞骚体、古体五七言、辞赋骈文、杂言歌行、聊斋志怪体、拟古记体 | 回答"这首诗该用什么句式/结构写" |
| [`mood/`](mood/index.md) | 按**情感基调**分类：潇洒激昂、个人悲伤、历史悲伤、闲适温情、诙谐自嘲、志怪奇趣 | 回答"这首诗该是什么情绪" |

`style` 和 `mood` 是两个正交的维度——同一情绪可以用不同文体表达，同一文体也能承载不同情绪。两边的分类文件里都以链接指向 `poems/` 里的具体原文，互不重复存放正文。

## AI 写诗前的检索流程（必须遵守）

在动笔写一首新诗/新篇之前，**先检索、后写作**，按以下顺序进行：

1. **拆解需求**：从用户的请求中提取三类信息——
   - 情感基调（如果用户没明说，从上下文/事件性质推断，例如"考试失败"→个人悲伤，"团聚游玩"→闲适温情）
   - 期望文体（如果用户没明说，结合情感基调和场合从 `style/index.md` 里选一个最贴合的；例如宏大历史感配楚辞骚体或辞赋，轻松记事配古体五七言）
   - 核心意象/主题关键词

2. **查 `mood/index.md`**，进入对应的情感基调文件，浏览其"特征"说明和代表作列表。

3. **查 `style/index.md`**，进入对应的文体文件，浏览其"特征"和"常用句式/结构模板"。

4. **查 `style/常用意象与母题.md`**，了解已有的核心意象库（月、剑、鲲鹏、青丝、酒等）——这是底色，但**不能止步于此**：
   - 从已有意象库里最多选 1-2 个作为"锚点"，让新作与整个诗集有辨识度上的连续性
   - 其余意象必须由 AI **自己创造**，围绕本次主题现造 2-3 个新的、之前的诗集里没出现过的意象或复合词（仿照作者"守月人""破晓之仙""木者"这类自造词的构词方式：抽象概念 + 具象名词，或身份/职能化的命名）
   - 写完后可以顺手在该意象旁标注一句"（新造意象）"，方便作者一眼看出哪些是延续、哪些是新增
   - 目的是让意象库像作者本人的创作一样持续生长，而不是几个固定意象来回复用

5. **通读该情感基调 + 该文体交集下的全部代表作原文**（不必限定篇数——上下文和 token 消耗可以忽略，读得越全，语感把握越准）。逐篇细读，重点看：
   - 开篇方式（是否有散文体"序"交代缘由）
   - 句式节奏（骚体的"兮"字位置、排比段落的重复规律）
   - 收尾手法（叩问式 / 放旷式 / 反转式 / 白话落差式）
   - 每篇独有的、不与其他篇撞车的细节手法

6. **动笔**：仿照第 5 步读到的结构和句法习惯写新作，把第 4 步造好的新意象自然嵌入其中。但**不得抄袭或轻微改写原文的具体句子**——只借鉴骨架、节奏、意象组合逻辑，措辞必须是全新的。

7. **写完后自查**：对照 `mood` 对应文件的"特征"描述，确认新作是否真的落在了目标情绪上，而不是滑向了邻近的类别（例如"个人悲伤"写着写着容易滑向"历史悲伤"，因为两者常共享意象）。

8. 如果这次创作用到了新的情感基调或文体（不在现有六类情绪/六类文体之内），写完后**主动提议**在 `mood/` 或 `style/` 下新增一个分类文件，并更新对应的 `index.md`，保持索引持续生长。

## 命名与收录规范（供后续新增作品参考）

- 新增作品统一存入 `poems/`，命名为 `YYYY-MM-DD_标题.md`
- frontmatter 至少含 `title` 和 `date`；非诗歌体裁（如志怪小说、寓言）加 `type` 字段
- 正文前若有散文体"序"，保留在正文顶部，不单独抽出
- 新增后需回头检查是否要加入 `mood/` 和 `style/` 对应分类文件的代表作列表
